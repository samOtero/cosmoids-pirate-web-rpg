# Captain's Voyage UI concepts

Created 2026-09-22 with the built-in image generation tool. Visual exploration only; no runtime assets or game behavior changed.

- `level-select-captains-chart-v1.png`: island-based progression and encounter briefing.
- `battle-command-deck-v1.png`: nautical battle HUD and creature portrait rail, using existing coastal background and four creature portraits as references.

These are illustrative concepts, not exact gameplay screenshots. The map's generated decorative slogans and sea name are not approved lore. Creature placements, levels, counters, terrain, and controls are illustrative. A production pass should reduce the battle rail height, preserve actual level geometry and creature sprites, and verify mobile readability.

### Battle command deck

Reference image 1 is the EXISTING top-down coastal grass battlefield: preserve its green grassy island, warm sand left and bottom, turquoise surf, tropical foliage and softly visible winding lane structure. Images 2-5 are existing Fueguana, Mopup, Palmit, Senticle portrait icons: reproduce these distinct creature identities in the bottom UI portraits, rather than generic monsters. The images are art/style/identity inputs, not whole-interface edit targets.
Create flat front-on screenshot, no physical monitor or angled desk, no collage. Clean all-ages painted adventure game finish, no pixel art, no neon glows, no baroque ornament or huge metal frames.
